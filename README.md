# Machine Learning y Datos Faltantes

Ejemplos de aplicación de métodos de aprendizaje automático en conjuntos de datos con valores faltantes.

Los ejemplos incluyen explicaciones metodológicas y código en Python y R.

## Ejemplos

1. Modelos de aprendizaje automático.
2. Análisis de conglomerados (Clustering).
3. Análisis de componentes principales (ACP).
